Könyvnyilvántartó API készítése

Készíts egy REST API alkalmazást Node.js, Express és better-sqlite3 felhasználásával!

Az alkalmazás könyveket tartalmazó adatbázist kezel. Az adatbázisban az alábbi mezők szerepelnek:

| Mező            | Típus
| -----------------  | -------------------------------------------------
| id                   | INTEGER (elsődleges kulcs, automatikusan növekvő)
| author           | TEXT
| title                | TEXT
| publishYear | INTEGER
| copies           | INTEGER

A szerver a **3000-es porton** fusson.

Adatbázis
Hozz létre egy SQLite adatbázist, amely tartalmazza a könyveket. Importáld az adatokat a CSV fájlból.

Példa rekord:
{
"id": 1,
"author": "Jókai Mór",
"title": "Az arany ember",
"publishYear": 1872,
"copies": 12
}

API végpontok

1. Könyvek lekérdezése szerző alapján
GET /api/books/author/:author

Lekérdezi a megadott szerző könyveit.
Példa kérés
GET /api/books/author/Jókai Mór
Sikeres válasz
[
{
"id": 1,
"author": "Jókai Mór",
"title": "Az arany ember",
"publishYear": 1872,
"copies": 12
},
{
"id": 2,
"author": "Jókai Mór",
"title": "A kőszívű ember fiai",
"publishYear": 1869,
"copies": 8
}
]

Hibaüzenet
{
"message": "No books found for this author"
}
HTTP státuszkód:
404 Not Found

2. Könyvek lekérdezése kiadási év alapján
GET /api/books/year/:year

Lekérdezi a megadott évben kiadott könyveket.
Példa kérés
GET /api/books/year/2020
Sikeres válasz
[
{
"id": 10,
"author": "Stephen King",
"title": "If It Bleeds",
"publishYear": 2020,
"copies": 5
}
]

Hibaüzenet
{
"message": "No books found for this year"
}
HTTP státuszkód:
404 Not Found

3. Új könyv létrehozása
POST /api/books
{
"author": "George Orwell",
"title": "1984",
"publishYear": 1949,
"copies": 10
}

Sikeres válasz
{
"message": "Book created successfully",
"id": 21
}
HTTP státuszkód:
201 Created

Hibaüzenet
{
"message": "Author, title, publishYear and copies are required"
}
HTTP státuszkód:
400 Bad Request

4. Könyv módosítása
PUT /api/books/:id

Példa kérés
PUT /api/books/3
{
"author": "George Orwell",
"title": "Animal Farm",
"publishYear": 1945,
"copies": 15
}

Sikeres válasz
{
"message": "Book updated successfully"
}

Hibaüzenet
{
"message": "Book not found"
}
HTTP státuszkód:
404 Not Found

5. Könyv törlése
DELETE /api/books/:id

Példa kérés
DELETE /api/books/3

Sikeres válasz
{
"message": "Book deleted successfully"
}

Hibaüzenet
{
"message": "Book not found"
}
HTTP státuszkód:
404 Not Found

Elvárások
* A szerver a 3000-es porton fusson. 1p
* Az adatbázisban tárolódjanak a könyvek. 3p
* Minden végpont legyen meg. 3p
* Minden végpont működjön megfelelően. 5p
* A kérések megfelelő státuszkódot és (hiba)üzenetet adjanak vissza. 3p
